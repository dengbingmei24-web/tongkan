# 同看发布验收清单

每次准备交付测试版或正式版时复制一份本清单，填写版本信息并逐项验收。自动化测试通过只是前置条件，真实 B站播放器、浏览器权限、标签页声音和跨网络 WebRTC 必须人工验证。

每次实际执行的设备、网络、结果和失败证据请填写 [`qa/TEST_RUN_TEMPLATE.md`](../../qa/TEST_RUN_TEMPLATE.md)，本文件只维护通用检查项目。

## 2. 房间与邀请

- [ ] 房主创建房间后能复制访客邀请链接。
- [ ] 访客使用邀请链接加入后，双方昵称和在线状态正确。

### 好友推送邀请

- [ ] 两部支持 FCM 的 Android 设备均安装同一 FCM 构建并登录已绑定账号。
- [ ] Android 13 及以上首次启用时能显示通知权限请求，允许后邀请通知可到达。
- [ ] 好友 App 位于后台或锁屏时，点击“一起看”能收到包含邀请人和房间信息的通知。
- [ ] 点击通知能打开 `/room/{roomId}#join={inviteKey}` 并进入现有加入房间流程。
- [ ] 拒绝通知权限、设备无有效 token 或推送失败时，邀请方仍自动打开系统分享兜底。

### 账号与唯一好友

- [x] QQ 邮箱验证码登录成功后，主页显示账号状态且匿名创建/加入房间仍可使用。
- [ ] 关闭并重新打开 App 时立即显示缓存账号主页，后台校验期间不阻塞首屏；明确鉴权失败后才返回登录页。
- [ ] 创建好友邀请码、复制、另一账号接受后，双方“我们”页都显示同一活动绑定。
- [ ] App 重启后唯一好友绑定能够从服务端恢复，未绑定账号不能调用好友邀请接口。
- [ ] 点击“邀请一起看”能创建房间并触发通知优先、系统分享兜底；访客深链只能使用访客密钥。
- [ ] 退出登录后本地 Session、缓存账号和已注册设备 token 均被撤销；重新打开 App 不恢复已退出账号。
- [ ] 非空 `tongkanAccountTestAccessToken` 未同时启用显式允许开关时，Android 构建必须失败。
- [ ] 访客链接不包含房主密钥。
- [ ] 第三个浏览器无法占用第三个席位。
- [ ] 页面刷新后能恢复身份、房间和最新权威播放状态。
- [ ] 错误或过期密钥会显示明确提示，不会进入假连接状态。

- [ ] 共享浏览器标签页时，对方能看到画面。

- [ ] 共享窗口和整个屏幕均能建立连接。
- [ ] 共享者主动停止后，对方画面立即结束并回到观看模式。

- [ ] 不同网络下完成一次共享；如果直连失败，15 秒内显示明确诊断。

- [x] 竖屏打开输入法后，顶层输入栏始终紧贴键盘上方；正在输入的文字、光标、连续删除反馈和 App 内“发送”按钮全部可见。

## 7.1 Android Alpha 9.3.2 P0 缓冲与同步稳定性

- [ ] 短暂缓冲少于 2 秒时，房间不会联动暂停，也不会持续显示明显缓冲提示。
- [ ] 同一方持续缓冲超过 2 秒时，只触发一次房间暂停，另一方不会收到重复暂停锚点。
- [ ] 缓冲恢复后只上报一次恢复状态，房间保持暂停，必须由任意一方手动播放后继续。
- [ ] 连续重复 5 次“短暂缓冲 / 长缓冲 / 恢复”，没有重复上报、状态卡死或播放暂停循环。
- [ ] 缓冲防抖等待期间切换视频或离开房间，不会在旧视频或旧房间补发延迟缓冲报告。
- [ ] 本机与房间进度偏差超过 1.5 秒并被硬同步时，竖屏状态区短暂显示“已重新同步 · 偏差 X.X 秒”。
- [ ] 横屏沉浸模式在缓冲期间保持控制层可见，缓冲恢复且手动播放后继续执行约 3 秒自动隐藏。
## 7.2 Android Alpha 9.3.3 播放器控制与跳转保护

- [ ] 竖屏点击视频区域只通过 App 桥接切换播放/暂停，不显示 B站原生进度条、中央暂停按钮或推荐入口。
- [ ] 竖屏连续点击视频区域 20 次，WebView 顶层 URL 不变化，App 不跳转到 B站视频页、活动页或推荐页。
- [ ] 横屏/全屏播放时，App 控制层显示后约 2.8 秒整体隐藏，播放状态下中央暂停按钮不常驻。
- [ ] 暂停、播放结束、缓冲、拖动进度或加载错误时控制层保持可见，中央仅显示“播放”按钮。
- [ ] 点击横屏视频区域只切换 App 控制层显隐，不把点击传递给 B站原生播放器皮肤。
- [ ] 通过 B站推荐、标题、作者、活动覆盖层和 `window.open` 触发的顶层导航均被阻止；视频、弹幕和同步桥接继续正常工作。
- [ ] 进入横屏、退出横屏、进入全屏和退出全屏后，原播放/暂停状态与进度保持不变。
## 7.3 Android Alpha 9.3.4 加载与方向状态

- [ ] 房间视频加载超过 8 秒时显示明确的“B站播放器加载较慢”状态，不再只显示黑屏和“已暂停”。

- [ ] 横屏切换产生的临时 pause 事件不会广播成房间暂停，也不会让另一台设备停下。
