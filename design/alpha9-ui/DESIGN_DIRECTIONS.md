# 同看 Alpha 9 UI 视觉方向

> 基于 ui-ux-pro-max 检索结果，结合原生 Android、双人私密房间、夜间观看和用户已确认流程进行二次适配。

> **已选择：C · 简洁工具感**。后续实现以 C 为主，不再并行推进 A、B。

## 共同 UX 规则

- 第一屏只展示昵称、创建房间、邀请链接和加入房间。
- 未进入房间前不展示播放器、进度条或调试状态。
- 所有主要触控区域不小于 48dp，相邻操作至少间隔 8dp。
- 输入框使用可见标签，不只依赖 placeholder。
- 网络操作超过 300ms 必须显示加载状态。
- 返回键行为可预测：观看页返回房间页，全屏状态返回先退出全屏。
- 全屏保持当前方向，不自动横屏；用户可手动选择横屏。
- 普通界面隐藏技术术语，诊断信息放入可展开区域。

## 方向 A：沉浸式影院感

- 关键词：OLED 深色、克制、夜间、视频优先、金色聚焦。
- 背景：`#08080F`
- 卡片：`#14131D`
- 主按钮：`#FFB454`
- 强调色：`#8B7CFF`
- 主文字：`#F7F5FA`
- 适合：长时间夜间观看，希望像一个真正的媒体应用。
- 风险：如果所有页面都过暗，入口表单可能显得冷，需要用暖色和留白缓和。

## 方向 B：温暖双人感

- 关键词：暖黑、柔和、亲密、轻松，不做粉色恋爱软件。
- 背景：`#1A1317`
- 卡片：`#2A1D23`
- 主按钮：`#FF9273`
- 强调色：`#F1C8A8`
- 主文字：`#FFF8F4`
- 适合：突出“我和另一个人正在一起看”，产品更有温度。
- 风险：暖色使用过多会影响视频内容，应限制在入口和状态区域。

## 方向 C：简洁工具感

- 关键词：米白、石墨、清楚、直接、轻量，不再像调试工具。
- 背景：`#F3F3F0`
- 卡片：`#FFFFFF`
- 主按钮：`#20211F`
- 强调色：`#5E7162`
- 主文字：`#171817`
- 适合：优先可理解性和日常操作，学习成本最低。
- 风险：观看时沉浸感弱，视频页需要自动切换到深色环境。

## 初步建议

不直接照搬技能生成的“科技霓虹”或“粉色约会”配色。更适合同看的方向可能是：

- 以方向 A 为观看页基础；
- 吸收方向 B 的暖色和双人在线状态；
- 使用方向 C 的表单清晰度和信息层级。

在用户选择前，预览页保留三个完整方向，不提前合并为最终方案。
