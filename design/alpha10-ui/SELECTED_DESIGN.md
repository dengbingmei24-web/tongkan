# 同看 Alpha 10 已选设计：Breath Tech

> 状态：已选择，作为 Alpha 10 Android 账号与双人空间的生产设计真源。
> 确认日期：2026-08-11
> 当前范围：登录、首页、片库、日历、“我们”与通用组件；观看页继续使用独立沉浸结构。
> 替代关系：本方案废止 Air/Cinema/Together 的生产方向，D-071 与 D-072 仅保留为历史探索。

## 1. 设计目标

Breath Tech 同时满足两种感觉：

- **科技感**：精确网格、状态编码、冷光连接点、单色反转按钮、克制等宽标签。
- **呼吸感**：大面积留白、低密度信息、弱边界、轻透明表面和一次性入场动效。
- **双人感**：通过连接轨道、双头像、共同时间和同步状态表达，不使用恋爱模板式粉色装饰。

明确禁止厚重拟物、古早渐变立体按钮、大面积玻璃卡、霓虹赛博背景、绿色主题和所有卡片同时悬浮。

## 2. 黑白主题

### 白色主题（默认）

- 背景：`#F7F8FA`
- 主文字：`#0B0D12`
- 次文字：`#777E8B`
- 面板：半透明白色，仅通过 1dp 边界区分
- 主操作：近黑 `#101218`，白色文字
- 连接强调：冷光蓝 `#637FFF`

### 黑色主题

- 背景：中性黑 `#05070A`，不使用绿色或蓝绿色底色
- 主文字：`#F5F7FA`
- 次文字：`#858C98`
- 面板：`rgba(15,18,24,.62)`
- 主操作：近白反转按钮，黑色文字
- 连接强调：冷光蓝 `#91A7FF`

冷光蓝只用于焦点、连接、选中、计划点和进度反馈；成功、在线等状态不能把整块界面染绿。

## 3. 几何与排版

- Android 画布：以 390×844 原型为基准，顶部使用打孔屏安全区。
- 页面边距：21dp；页面内容从系统状态栏下方开始。
- 标题：31sp，紧字距，标题上方使用 9sp 等宽状态编码。
- 正文：10-13sp；正文行高至少 1.45。
- 主按钮：最小 48dp 触控高度，视觉圆角 14dp。
- 图标按钮、筛选、日期：原型至少 44px，Android 实现至少 48dp 触控区域。
- 卡片：14-19dp 圆角；普通列表保持边到边，不使用重复悬浮卡片。
- 图标：统一 1.7-1.8dp 线性矢量图标，不使用 Emoji 作为结构图标。

## 4. 页面结构

### 登录

- TK 信号标记、主题切换、简短价值说明、邮箱输入、获取验证码。
- 保留“暂时使用匿名房间”次操作。
- 明确“每个账号仅绑定一位好友”和内容流不经过同看服务器。

### 首页

- 顶部显示双人连接轨道和延迟状态。
- 房间主舞台直接暴露“创建房间 / 加入房间”，不藏进更多菜单。
- 下方展示今日计划与本月共同数据，不堆叠无关信息。

### 片库

- 搜索、线性筛选、最近更新列表和固定添加操作。
- 海报只作为识别缩略图，不让媒体封面占据整个页面。
- 完全共享的添加、排序、分类和计划能力沿用账号 PRD。

### 日历

- 月历为主视觉，计划点使用冷光蓝。
- 日期详情通过时间线显示具体时间与“当天”项目。
- 日期必填，开始时间与备注可选；首版不加入提醒和重复计划。

### 我们

- 双头像连接轨道、绑定天数、累计时长和共同完成数量。
- 历史、归档、账号设置直接展示。
- 解绑使用危险描边按钮，不和主操作竞争。

## 5. 交互反馈

- 按压反馈在 80-150ms 内出现：颜色、边界、阴影或轻缩放至少有一种明显变化。
- 异步按钮立即替换为“正在处理”与 Spinner，并禁用重复点击。
- 成功后按钮短暂显示完成状态，同时展示 Toast，例如“房间已创建”。
- Drawer 从底部进入，负责添加片库、创建计划、粘贴邀请和解绑确认。
- 入场动效只做一次 420ms 分层出现；列表滚动时不重复播放。
- 尊重 `prefers-reduced-motion`，Android 实现尊重系统动画缩放设置。
- 关键创建、保存和解绑结果可以使用轻触觉反馈；普通导航不振动。

## 6. Android 原生实现映射

- 继续使用 Java View，不引入 Kotlin、Compose、React 或 shadcn 运行时。
- 使用 XML shape / `GradientDrawable` 表达黑白表面、边界和圆角。
- 使用有边界 Ripple、`StateListAnimator` 或按压监听表达即时反馈。
- 使用 Window Insets 处理状态栏、导航栏和横竖屏安全区。
- 竖屏观看页的消息列表保留在下半区卡片内，输入栏作为根 `FrameLayout` 的独立顶层控件；键盘出现时只抬升输入栏，不移动视频、控制栏或整张消息卡片。
- 建议把账号、四个主页面和播放器职责从 `MainActivity.java` 拆分为独立 Java View/Controller，不做大型框架重写。

## 11. Alpha 10.2.1 片库体验

- 添加视频使用贴底面板，不再使用占据屏幕中心的大型系统输入框。
- 输入区下方实时逐条标记“已识别”“短链待解析”“无法识别”“超过上限”；只有 1–20 条全部可识别时才能提交。
- 服务端返回后在片库页逐条显示已添加、重复或失败原因；`B23_RESOLUTION_FAILED` 显示为短链失效或视频不可用，不再只给出容易误导的稍后重试建议。
- 默认片库按自定义分类和未分类分区展示；每个条目使用 16:9 封面、标题、UP 主/BV、观看状态和主要操作，搜索、筛选或排序时恢复单一结果流。
- 房间竖屏从底部抽屉搜索和选择片库视频；横屏/全屏从右侧抽屉选择，抽屉打开时视频保持可见。手动粘贴链接仍作为同层入口保留。
- 封面加载使用原生 HTTPS、大小限制、下采样和内存缓存，不引入第三方图片库；无封面或加载失败时显示主题占位色。

## 12. Alpha 10.2.3 日常操作修复

- 首页账号状态卡始终提供明确操作：匿名用户显示“登录账号”，临时匿名模式显示“返回某某的账号”，账号模式显示“管理账号与好友”。
- “我们”页账号卡前置“进入匿名模式”和“切换登录账号”；退出或切换后验证码表单恢复到可重新输入邮箱的初始状态。
- 解绑只保留一个选择面板，两个选项直接说明解绑后的旧空间结果；请求期间禁用重复操作，完成后以服务端权威状态刷新。
- “邀请好友一起看”先展示对象和通知/分享说明；从片库点击同看时直接携带当前视频创建房间并优先通知唯一好友。通知不可用时显示复制链接和系统分享按钮，不再静默跳出。
- 视频更多操作新增“重命名视频”；封面请求固定 JPEG 缩略图以覆盖 Android 8+ 解码能力。

## Alpha 10.2.4 活跃好友房间

- 登录且已绑定好友的一方创建房间后，房间会在完成 WebSocket 鉴权后自动发布到当前双人空间，默认展示 10 分钟。
- 另一方无需接收通知或复制链接：首页每 10 秒刷新一次，出现“好友正在等你一起看”卡片后可直接进入。
- FCM 仅用于提醒，不再决定房间是否可发现；通知被拒绝、token 缺失或推送失败时，对方仍可从首页进入。
- 每个 pair 同时只有一个活跃房间；新房间覆盖旧房间。房主离开、记录过期或好友解绑后立即不可见。
- Account Worker 只保存加密访客邀请 URL，不保存 host key；读取必须命中当前活动 pair，创建者和第三方都不会获得加入入口。

## 14. Alpha 10.3 日历实施映射

- 原生 `CalendarScreen` 使用月份前后切换、星期标题和七列月格；有任意计划的日期显示冷光蓝圆点与弱描边，选中日期使用冷光蓝反转状态。
- 日期详情按稳定顺序展示封面、标题、“当天”或 `HH:mm`、`PLANNED/COMPLETED`、备注和最近更新者；当前空间提供编辑、标记完成/恢复待看与取消计划，keep 旧空间隐藏写入控件并明确只读。
- 新建计划先从共同片库选择视频；日期必填，开始时间与备注可选。片库条目的“安排日期”复用同一编辑流程，避免重复输入媒体信息。
- 首页“今天想看”只展示当天未完成计划，并按有时间项在前、无时间项在后排序；“开始同看”继续复用现有房间、活跃好友房间和可选 FCM 提醒链路。
- 旧空间日历从“保留的旧空间”进入，可切换月份、查看历史计划并返回当前空间；匿名、未登录、未绑定、加载和错误状态都有独立可恢复文案。
- Alpha 10.3 月格只表达日历计划，不表达真实共同观看记录；实际观看实心点/双标记、自动提醒、重复计划和外部日历仍不在本版设计范围。
- 状态（2026-08-21）：上述 UI 已在 `codex/TK-004-calendar` 本地集成并通过 Android 55/55、Lint 与 Debug 构建；用户已确认当前 Breath Tech/nav-v3 真机视觉验收通过。双设备日历和日常使用矩阵仍单独验收。

- 2026-08-21 收录外部设计软件产出的高保真参考稿：`design/alpha10-ui/breath-tech-screens.html`。该文件用于页面结构、文案层级、状态表达和视觉细节对照，不作为 Android 运行时代码直接嵌入。

- 共同片库的筛选、分类管理、分类重命名/排序/删除、视频更多操作、移动分类、重命名和删除确认统一为 Breath Tech 贴底面板；长内容支持最大 88% 屏高和纵向滚动。

## 16. Alpha 10.4 历史与统计实施映射

- 保持“首页 / 片库 / 日历 / 我们”四个主 tab，不新增历史 tab；当前 pair 的月度摘要和最近共同观看记录放在“我们”账号/好友信息之后。
- 月度摘要只展示已冻结且可信的数据：本月共同观看时长、观看次数、不同视频数和最近同看日期；完成数量在首切片保持隐藏。
- 历史条目复用 16:9 封面、标题、BV/分P、日期和共同观看时长；标题或封面缺失时使用现有主题占位，不阻塞列表。
- 日历月格同时表达计划与实际观看：保留现有计划冷光蓝点，新增可区分的实看实心点；两者同日时并列而不是互相覆盖。
- 日期详情分为“计划”和“一起看过”两个区块；实际记录不出现完成计划按钮，也不自动修改计划状态或 calendar revision。
- keep 旧空间使用现有只读归档入口展示历史/月度/日历实看记录；pending、delete 和第三方不显示入口。
- loading、空、错误和 metadata fallback 使用现有 Breath Tech 面板与重试按钮；历史服务失败不能遮挡账号、房间、片库或日历计划。
